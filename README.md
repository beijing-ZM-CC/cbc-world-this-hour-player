# 双子座 · CBC Radio 双语字幕网页播放器

自动同步 CBC Radio 官方最新新闻广播并提供免费中英文双语同步滚动字幕的网页播放器。

## 功能特点
- **三段式清晰布局**：顶部播放控制栏（播放/暂停、`-5s` 快退、`+5s` 快进、倍速、音量、期数选择、保存、同步最新、深浅主题）+ 中部全宽超长进度条 + 底部左右双栏（左英右中）同步向上滚动并高亮当前句。
- **多节目 & 自动归档**：
  - **The World This Hour**（每小时 5 分钟新闻）：后台每 15 分钟自动检测最新一期，并将每小时音频与字幕自动归档保存至本地（最多保留 48 期）。
  - **World Report**（每日 10 分钟晨间新闻）与 **Your World Tonight**（每日 30 分钟晚间新闻）：自动拉取最新多天期数，点选即播并自动生成双语字幕。
- **保存到本地硬盘**：点击顶部「保存」按钮，可将当前选中的音频文件（`.mp3`）、英文字幕（`.srt`）、中文字幕（`.srt`）、双语对照字幕（`.srt`）、双语文本（`.txt`）单独保存或一键打包下载（`.zip`）。
- **100% 免费本地转写与翻译**：使用 `faster-whisper`（本地 CPU）+ 免费英译中，无需任何付费 API Key。
- **外网访问**：内置便携版 `cloudflared`（Cloudflare Quick Tunnel），一键生成公网 HTTPS 访问链接。

## 启动方式

在项目目录下运行 PowerShell 脚本：

```powershell
.\start_public.ps1
```

- 本地访问地址：`http://127.0.0.1:8765`
- 外网访问地址：终端输出中 `https://xxxx.trycloudflare.com` 即为公网 HTTPS 链接（本机保持开机即可访问）。

## 快捷键
- `Space`：播放 / 暂停
- `←` / `→`：快退 / 快进 5 秒
- 点击任意英文或中文字幕：直接跳转至该句播放
